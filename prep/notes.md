## 2. ⚠️ 关键发现：不能"删掉所有 HETATM"

实际下载的文件里，**HETATM 不等于"无关杂原子"**。逐个体检结果：

### 1EMA（GFP）— HETATM 共 149 个

| 残基名 | 原子数 | 是什么 | 处理 |
|---|---|---|---|
| `CRO` | 22 | **发色团**（对羟基苄叉咪唑啉酮），本题的高亮目标 | **必须保留** |
| `MSE` | 32 | **硒代甲硫氨酸**（该结构为 SeMet 表达产物，用 MSE 替代 MET） | **必须保留**，它是蛋白链的一部分 |
| `HOH` | 95 | 水分子 | 删除 |

- `CRO` 在文件中是 `HETATM` 记录（残基 A/66），**不是** `ATOM`。所以一旦用 `grep -v HETATM` 这种粗暴规则，发色团和 4 个 MSE 会一起消失，蛋白链还会在相应位置断开。
- CRO 与相邻残基共价相连（REMARK 999 说明它由自催化反应生成）。可视化时它是链内的一段，不是游离小分子。
- 无 altloc（第 17 列全空），不需要选构象。

### 1M17（EGFR + 厄洛替尼）— HETATM 共 49 个

| 残基名 | 原子数 | 处理 |
|---|---|---|
| `AQ4` | 29 | 高亮目标（药物分子），保留 |
| `HOH` | 20 | 删除 |

- 只有 A 链（无其他蛋白链），无糖基/离子类杂原子。

### 1BRS（Barnase–barstar）— 实际有 **6 条链**

| 链 | 分子 | 原子数 | 处理 |
|---|---|---|---|
| A | Barnase | 1,009 | **保留** |
| B | Barnase | 1,015 | 删除 |
| C | Barnase | 889 | 删除 |
| D | Barstar | 772 | **保留** |
| E | Barstar | 729 | 删除 |
| F | Barstar | 739 | 删除 |

- 非水 HETATM：**没有**。全部 513 个 HETATM 都是 `HOH`。
- 这就是题目特别强调"仅保留 A、D 链"的原因：该晶体里有多拷贝，全开就变成一个 6 链巨型复合物，接触残基也会算串。

## 3. 预处理规则（最终版）

统一原则：**按"链白名单 + 残基名白名单"删，而不是按记录类型删。**

| PDB | 保留 | 删除 |
|---|---|---|
| 1EMA | 链 A 全部 ATOM + `CRO` + `MSE` | `HOH` |
| 1M17 | 链 A 全部 ATOM + `AQ4` | `HOH` |
| 1BRS | 链 A、D 的全部 ATOM | 链 B/C/E/F 全部 + 所有 `HOH` |

## 4. 接触残基判据（题目原文）

> 某残基的任一重原子（不含氢）与高亮目标的任一重原子距离 **≤ 5 Å**，该残基即为接触残基。

实现约定：

- 重原子 = 元素列不为 `H`（按 PDB 第 77–78 列 element 字段判断，不靠原子名猜）。
- 欧氏距离，单位 Å；比较时用距离平方，避免开方。
- **1BRS 必须双向**：A 链中靠近 D 的残基 + D 链中靠近 A 的残基。目标集合 = 对侧链的全部重原子。
- 输出文件：`prep/contacts/<ID>.json`

```jsonc
{
  "pdb": "1M17",
  "target": { "kind": "ligand", "name": "AQ4", "atoms": 29 },
  "criterion": { "type": "heavy-atom", "cutoff": 5.0, "unit": "angstrom" },
  "residues": [{ "chain": "A", "resi": 769, "resn": "MET", "minDist": 2.83 }]
}
```
